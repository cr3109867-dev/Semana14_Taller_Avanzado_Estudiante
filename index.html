Situacion inicial

La vereda El Progreso quiere publicar una pagina para una feria escolar y rural. La pagina debe permitir consultar informacion, revisar datos de participacion e inscribirse a un taller.

Accesibilidad debil

Algunos elementos no explican bien su funcion o no son faciles de interpretar.

Responsive incompleto

Algunas tarjetas y textos deben revisarse para funcionar mejor en celular.

Errores de consola

Existe una accion que genera error al hacer clic. Debes encontrarla y corregirla.

Optimizacion pendiente

Hay codigo repetido y partes que pueden quedar mas limpias y faciles de mantener.

Criterios de mejora

Usa estos criterios para revisar y corregir la pagina.

Usabilidad

Los botones, textos y rutas de navegacion deben ser faciles de entender.

Accesibilidad

La pagina debe incluir labels, alt, contraste, mensajes claros y navegacion comprensible.

Estructura

El HTML debe organizarse con secciones, titulos y componentes reutilizables.

Optimizacion

El proyecto debe cargar bien, tener codigo limpio y no mostrar errores en consola.
