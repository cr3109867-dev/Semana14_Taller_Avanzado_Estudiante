# Rubrica de evaluacion - Semana 14

| Criterio | Superior | Alto | Basico | Bajo |
|---|---|---|---|---|
| Instalacion y ejecucion | Instala dependencias, ejecuta el proyecto y evidencia el proceso correctamente. | Ejecuta el proyecto con pequenos problemas documentados. | Logra abrir parcialmente el proyecto pero con poca evidencia. | No logra ejecutar o no entrega evidencia. |
| Usabilidad | Mejora botones, instrucciones, mensajes y flujo de usuario de forma clara. | Realiza varias mejoras de claridad aunque algunas quedan generales. | Aplica cambios superficiales sin justificar bien. | No evidencia comprension de usabilidad. |
| Accesibilidad | Corrige labels, alt, contraste y mensajes accesibles con buena justificacion. | Corrige la mayoria de elementos accesibles solicitados. | Corrige pocos elementos o deja errores importantes. | No aplica criterios de accesibilidad. |
| Diseno y estructura | Organiza visualmente la pagina y mantiene estructura semantica clara. | Mejora la estructura general con algunos detalles pendientes. | Realiza cambios minimos de presentacion. | Desorganiza la estructura o no modifica. |
| JavaScript y depuracion | Corrige errores de consola, mejora validaciones y prueba escenarios. | Corrige el error principal y algunas validaciones. | Corrige parcialmente, pero quedan fallos. | No corrige errores de funcionamiento. |
| Optimizacion | Limpia codigo, reduce repeticion y ejecuta revision automatica. | Aplica algunas mejoras de limpieza y revision. | Presenta optimizacion limitada. | No realiza optimizacion. |
| Evidencias | Entrega capturas completas: antes, despues, consola y check. | Entrega la mayoria de evidencias. | Entrega pocas evidencias o incompletas. | No entrega evidencias verificables. |
| Documentacion | Informe completo, claro y reflexivo. | Informe claro pero con poca profundidad en algunas partes. | Informe incompleto o muy breve. | No documenta el proceso. |
