# Lista de chequeo antes de entregar

Marca cada punto antes de subir la tarea a Moodle.

## Instalacion y ejecucion

- [ ] Abri el proyecto en VS Code.
- [ ] Ejecute `npm install`.
- [ ] Ejecute `npm run dev`.
- [ ] La pagina abrio correctamente en el navegador.

## HTML y accesibilidad

- [ ] La imagen principal tiene atributo `alt`.
- [ ] Todos los campos del formulario tienen `label` asociado.
- [ ] El contenedor de mensajes usa `aria-live` o `role="alert"`.
- [ ] Los textos de botones son claros.
- [ ] La estructura usa `header`, `nav`, `main`, `section` y `footer` correctamente.

## CSS y diseno

- [ ] Mejore el contraste del texto principal.
- [ ] Revise que el sitio se vea bien en celular.
- [ ] Reduje codigo CSS repetido.
- [ ] Mantengo coherencia visual entre tarjetas, botones y formularios.

## JavaScript

- [ ] Corregi el error de consola del boton de diagnostico.
- [ ] Valide que el telefono tenga exactamente 10 digitos.
- [ ] Valide que el usuario acepte la autorizacion de datos.
- [ ] Mejore los mensajes de error y exito.
- [ ] La consola del navegador no muestra errores rojos.

## Evidencias

- [ ] Guarde captura del antes.
- [ ] Guarde captura del despues.
- [ ] Guarde captura de consola sin errores.
- [ ] Guarde captura o resultado de `npm run check`.
- [ ] Complete el informe de entrega.
- [ ] Complete el diagnostico inicial.

## Entrega

- [ ] Comprimi el proyecto en ZIP.
- [ ] No inclui `node_modules`.
- [ ] El archivo tiene mi nombre.
- [ ] Subi el archivo o enlace a Moodle.
